# MultiBrowser, этап 1: как собрать .exe на GitHub

1. Зайди на github.com, войди в аккаунт (или зарегистрируйся) и нажми «New repository». Назови, например, `multibrowser`, выбери **Private**, нажми «Create repository».
2. Распакуй этот архив. На странице репозитория нажми «uploading an existing file» и перетащи **всё содержимое папки**, включая скрытую папку `.github`. Нажми «Commit changes».
3. Открой вкладку **Actions**, слева выбери **build**, нажми **Run workflow**.
4. Через 5–15 минут сборка закончится. Открой её и внизу в разделе **Artifacts** скачай `MultiBrowser-Setup`. Внутри лежит установщик `.exe`.
5. Если сборка упала (красный крестик), открой неудавшийся шаг, скопируй последние строки лога и пришли мне. Я поправлю.

## Что умеет этап 1
Создание профилей, запуск движка с отдельной папкой данных и отпечатком, прокси (SOCKS5/HTTP без логина), загрузка VPN-конфига `.conf` (WireGuard, AmneziaWG: Proton, WARP через wgcf и подобные).
Секреты шифруются средствами Windows. Пока VPN работает, расшифрованный конфиг лежит во временном файле и удаляется при закрытии профиля.
