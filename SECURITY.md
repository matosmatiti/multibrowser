# Безопасность

## Как сообщить об уязвимости
Не создавай публичный Issue. Открой вкладку **Security** репозитория и нажми **Report a vulnerability** (закрытое сообщение владельцу).

## Что важно знать
- Обновления приложение берёт из релизов этого репозитория. Доступ к аккаунту владельца даёт возможность выпустить обновление, поэтому у владельца включены двухфакторная защита и защита ветки main.
- Пароли прокси и VPN-конфиги хранятся на компьютере пользователя в зашифрованном виде (Windows DPAPI). Остальные данные профилей на диске не шифруются целиком: используй BitLocker и отдельную учётную запись Windows.
- Локальный API выключен по умолчанию, слушает только 127.0.0.1 и требует токен.
- Движок усиленного режима, ядра подключений и Electron закреплены на конкретных версиях (`versions.json`, `package.json`). Новые версии подбирает еженедельный workflow `update-deps`: только стабильные, старше 3 дней, и по умолчанию через запрос на слияние, который подтверждает владелец.
